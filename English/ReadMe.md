# 📘 WordKing Vocabulary Learning App Overview (English)

## 🌟 Introduction
WordKing is a vocabulary learning tool designed for efficient word memorization. It is suitable for English learners, exam preparation, and anyone building vocabulary over time. With scientific memory techniques and flexible learning modes, WordKing helps users master words in a structured and effective way.

## 🚀 Core Features

### 🧠 Multiple Learning Modes
- **Learning Mode**: Focus on initial word memorization
- **Review Mode**: Reinforce memory with spaced repetition
- **Test Mode**: Simulate quizzes to evaluate progress
- **Quick Browse**: Learn lightly during short breaks

### ⏳ Smart Review Scheduling
- Uses the **Ebbinghaus Forgetting Curve** to schedule reviews
- Adjusts review frequency according to mastery level
- Reduces unnecessary repetition and improves efficiency

### 📊 Detailed Learning Analytics
- Visual progress tracking for learned, unlearned, and reviewing words
- Daily statistics and learning trends
- Streak and mastery tracking

### 📚 Flexible Vocabulary Management
- Supports multiple vocabulary lists for exams, daily use, and professional needs
- Custom word list import
- Categories and tags for organization

### 🎯 Goal Setting
- Custom daily learning goals
- Reminders for unfinished tasks
- Streak-based motivation

---

## 🎉 Conclusion
WordKing is more than a vocabulary app; it is a comprehensive solution for effective word learning. Smart scheduling and data insights make vocabulary building more efficient, easier, and sustainable.
