# WordKing — Piranti sinau pinter kanggo ngapalake kosakata basa Indonesia kanthi efisien

**WordKing** yaiku aplikasi pinter kanggo ngapalake kosakata sing dirancang kanggo para siswa basa Indonesia. Kanthi algoritma memori ilmiah, macem-macem mode sinau, lan mekanisme pengulangan adhedhasar data, aplikasi iki mbantu pangguna nguwasani luwih akeh tembung kanthi mantep ing wektu sing luwih cekak.

Apa sampeyan lagi nyiapake ujian (IELTS / TOEFL / ujian pascasarjana), ningkatake kemampuan ngomong, utawa nambah kosakata basa Indonesia saben dina, WordKing nyedhiyakake pengalaman sinau sing sistematis lan efisien.

---

## 🚀 Fitur utama

### 📚 Macem-macem mode sinau
- Mode ngapalake tembung: ndeleng lan mangerteni teges tembung kanthi cepet
- Mode tes ejaan: nguatake kemampuan nulis ejaan
- Mode latihan ngrungokake: ningkatake kemampuan ngrungokake lan mbedakake
- Mode pilihan ganda: nguwatake pangerten lan pambeda

> Latihan saka pirang-pirang arah nggawe memori kosakata luwih kuwat

---

### 🧠 Algoritma pengulangan pinter
- Kanthi otomatis ngatur wektu pengulangan adhedhasar kurva lali
- Kanthi otomatis ngenali tembung sing wis dikuasai / gampang salah / durung dikuasai
- Ngoptimalake jalur sinau kanthi dinamis

> Gunakake wektu ing bagean sing paling perlu diulang

---

### 📊 Analisis data sinau
- Statistik sinau saben dina
- Tren tingkat bener
- Visualisasi kemajuan memori
- Cathetan dina sinau berturut-turut

> Data mbantu kemajuan lan nambah motivasi sinau

---

### 🎯 Rencana sinau pribadi
- Ngatur target sinau saben dina (30 / 50 / 100 tembung)
- Ndhukung macem-macem bank tembung (ujian / saben dina / kustom)
- Cocog kanggo wektu sinau sing cekak lan kapisah-pisah

> Nyocogake irama sinau pangguna sing beda-beda

---

## 📖 Pandhuan panggunaan

### 1️⃣ Pilih bank tembung
Bukak aplikasi lan pilih buku tembung sing cocog kanggo sampeyan, kayata CET-4/6, IELTS, TOEFL, utawa bank tembung kustom.

### 2️⃣ Setel target
Setel jumlah sinau saben dina miturut wektu sampeyan, contone:
- Wiwitan: 30 tembung / dina
- Peningkatan: 50 tembung / dina
- Intensif: 100 tembung / dina

### 3️⃣ Miwiti sinau
Sinaua tembung liwat macem-macem mode lan rampungna tes sing cocog.

### 4️⃣ Baleni miturut rencana
Sistem kanthi otomatis ngelingake pengulangan lan luwih fokus nguatake tembung sing gampang dilalekake.

### 5️⃣ Deleng data
Ing statistik sinau, delengen asil sinau lan tren kemajuan sampeyan.

---

Mekanisme pengulangan pinter adhedhasar kurva lali ningkatake efisiensi memori.

### ✅ Sinau efisien
Nyuda pengulangan sing ora efektif lan fokus marang isi utama.

### ✅ Motivasi terus-terusan
Umpan balik data lan mekanisme check-in nambah motivasi sinau.

### ✅ Fleksibel lan praktis
Sinau kapan wae lan ing ngendi wae, nggunakake wektu luang kanthi maksimal.
