# 📘 Ikhtisar Aplikasi Belajar Kosakata WordKing

## 🌟 Pendahuluan
WordKing adalah alat belajar kosakata untuk menghafal kata dengan efisien. Cocok untuk pelajar bahasa Inggris, persiapan ujian, dan siapa pun yang ingin membangun kosakata dari waktu ke waktu. Dengan teknik memori ilmiah dan mode belajar fleksibel, WordKing membantu pengguna menguasai kata secara terstruktur dan efektif.

## 🚀 Fitur Utama

### 🧠 Berbagai Mode Belajar
- **Mode Belajar**: Focus on initial word memorization
- **Mode Ulasan**: Reinforce memory with spaced repetition
- **Mode Tes**: Simulate quizzes to evaluate progress
- **Jelajah Cepat**: Learn lightly during short breaks

### ⏳ Jadwal Ulasan Cerdas
- Uses the **Ebbinghaus Forgetting Curve** to schedule reviews
- Adjusts review frequency according to mastery level
- Reduces unnecessary repetition and improves efficiency

### 📊 Analisis Belajar Terperinci
- Visual progress tracking for learned, unlearned, and reviewing words
- Daily statistics and learning trends
- Streak and mastery tracking

### 📚 Manajemen Kosakata Fleksibel
- Supports multiple vocabulary lists for exams, daily use, and professional needs
- Custom word list import
- Categories and tags for organization

### 🎯 Penetapan Tujuan
- Custom daily learning goals
- Reminders for unfinished tasks
- Streak-based motivation

## 🎉 Kesimpulan
