# 📘 WordKing-sanastosovelluksen yleiskatsaus

## 🌟 Johdanto
WordKing on sanaston oppimistyökalu, joka on suunniteltu sanojen tehokkaaseen muistamiseen. Se sopii englannin opiskelijoille, kokeisiin valmistautumiseen ja kaikille, jotka haluavat kasvattaa sanavarastoaan ajan myötä. Tieteelliset muistitekniikat ja joustavat tilat tekevät oppimisesta järjestelmällistä ja tehokasta.

## 🚀 Keskeiset ominaisuudet

### 🧠 Useita oppimistiloja
- **Oppimistila**: sanojen ensimmäinen muistaminen
- **Kertaustila**: vahvistaa muistia hajautetulla kertauksella
- **Testitila**: arvioi edistymistä visoilla
- **Nopea selaus**: kevyt opiskelu lyhyillä tauoilla

### ⏳ Älykäs kertausaikataulu
- Käyttää **Ebbinghausin unohtamiskäyrää**
- Säätää tiheyttä osaamistason mukaan
- Vähentää turhaa toistoa ja parantaa tehokkuutta

### 📊 Tarkat oppimisanalyysit
- Visuaalinen seuranta opituista, oppimattomista ja kerrattavista sanoista
- Päivittäiset tilastot ja oppimistrendit
- Putken ja sanahallinnan seuranta

### 📚 Joustava sanaston hallinta
- Listat kokeisiin, arkeen ja ammatillisiin tarpeisiin
- Omien sanalistojen tuonti
- Kategoriat ja tunnisteet järjestämiseen

### 🎯 Tavoitteet
- Mukautettavat päivätavoitteet
- Muistutukset keskeneräisistä tehtävistä
- Motivaatio opiskelupuken kautta
---

## 🎉 Yhteenveto
WordKing on enemmän kuin sanastosovellus; se on kokonaisratkaisu tehokkaaseen sanojen oppimiseen. Älykäs aikataulutus ja data tekevät sanaston kartuttamisesta helpompaa, tehokkaampaa ja kestävää.
