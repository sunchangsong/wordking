# 📘 نمای کلی برنامه یادگیری واژگان WordKing

## 🌟 معرفی
WordKing ابزاری برای یادگیری واژگان است که برای حفظ مؤثر کلمات طراحی شده است. برای زبان‌آموزان انگلیسی، آمادگی آزمون و هر کسی که می‌خواهد به مرور زمان دایره واژگان خود را گسترش دهد مناسب است. با روش‌های علمی حافظه و حالت‌های انعطاف‌پذیر، یادگیری را منظم و مؤثر می‌کند.

## 🚀 ویژگی‌های اصلی

### 🧠 أوضاع تعلم متعددة
- **وضع التعلم**: التركيز على حفظ الكلمات لأول مرة
- **وضع المراجعة**: تعزيز الذاكرة بالتكرار المتباعد
- **وضع الاختبار**: محاكاة الاختبارات لقياس التقدم
- **التصفح السريع**: مناسب للتعلم الخفيف في الاستراحات القصيرة

### ⏳ جدولة مراجعة ذكية
- يحدد المراجعات وفق **منحنى النسيان لإبينغهاوس**
- يغير التكرار حسب مستوى الإتقان
- يقلل التكرار غير الضروري ويرفع الكفاءة

### 📊 تحليلات تعلم مفصلة
- تتبع مرئي للكلمات المتعلمة وغير المتعلمة وقيد المراجعة
- إحصاءات يومية وتحليل اتجاهات التعلم
- تتبع سلسلة الاستمرار وإتقان الكلمات

### 📚 إدارة مرنة للمفردات
- يدعم قوائم للامتحانات والاستخدام اليومي والمجالات المهنية
- استيراد قوائم كلمات مخصصة
- تصنيفات ووسوم لتنظيم أفضل

### 🎯 تحديد الأهداف
- أهداف يومية قابلة للتخصيص
- تذكيرات بالمهام غير المكتملة
- نظام تحفيز يعتمد على الاستمرارية

## 🎉 جمع‌بندی
WordKing فراتر از یک برنامه واژگان است؛ یک راهکار کامل برای یادگیری مؤثر کلمات است. زمان‌بندی هوشمند و تحلیل داده‌ها ساختن واژگان را آسان‌تر، کارآمدتر و پایدارتر می‌کند.
