# 📘 ภาพรวมแอปเรียนคำศัพท์ WordKing

## 🌟 บทนำ
WordKing เป็นเครื่องมือเรียนคำศัพท์ที่ออกแบบมาเพื่อช่วยจำคำได้อย่างมีประสิทธิภาพ เหมาะสำหรับผู้เรียนภาษาอังกฤษ การเตรียมสอบ และทุกคนที่ต้องการสะสมคำศัพท์ในระยะยาว ด้วยเทคนิคความจำเชิงวิทยาศาสตร์และโหมดการเรียนที่ยืดหยุ่น WordKing ช่วยให้เรียนคำศัพท์ได้เป็นระบบและได้ผล.

## 🚀 ฟีเจอร์หลัก

### 🧠 โหมดการเรียนหลายแบบ
- **โหมดเรียน**: เน้นการจำคำครั้งแรก
- **โหมดทบทวน**: เสริมความจำด้วยการทบทวนแบบเว้นระยะ
- **โหมดทดสอบ**: ทำแบบทดสอบเพื่อวัดความก้าวหน้า
- **เรียกดูด่วน**: เหมาะกับการเรียนเบา ๆ ระหว่างพักสั้น ๆ

### ⏳ ตารางทบทวนอัจฉริยะ
- ใช้ **เส้นโค้งการลืมของ Ebbinghaus** เพื่อจัดตาราง
- ปรับความถี่ตามระดับความเชี่ยวชาญ
- ลดการทบทวนที่ไม่จำเป็นและเพิ่มประสิทธิภาพ

### 📊 การวิเคราะห์การเรียนละเอียด
- ติดตามคำที่เรียนแล้ว ยังไม่เรียน และกำลังทบทวนแบบมองเห็นได้
- สถิติรายวันและแนวโน้มการเรียน
- ติดตาม streak และระดับความจำคำ

### 📚 จัดการคำศัพท์ยืดหยุ่น
- รองรับรายการสำหรับสอบ ใช้ประจำวัน และงานอาชีพ
- นำเข้ารายการคำเองได้
- ใช้หมวดหมู่และแท็กเพื่อจัดระเบียบ

### 🎯 ตั้งเป้าหมาย
- ตั้งเป้าหมายรายวันเองได้
- แจ้งเตือนงานที่ยังไม่เสร็จ
- สร้างแรงจูงใจจาก streak
---

## 🎉 สรุป
WordKing ไม่ใช่แค่แอปคำศัพท์ แต่เป็นทางออกครบถ้วนสำหรับการเรียนคำอย่างมีประสิทธิภาพ ตารางทบทวนอัจฉริยะและข้อมูลเชิงลึกช่วยให้การเพิ่มคลังคำศัพท์ง่ายขึ้น มีประสิทธิภาพขึ้น และต่อเนื่องได้จริง.
