# 📘 Prezentare generală a aplicației WordKing pentru vocabular

## 🌟 Introducere
WordKing este un instrument de învățare a vocabularului conceput pentru memorarea eficientă a cuvintelor. Este potrivit pentru cei care învață engleză, se pregătesc pentru examene sau vor să își dezvolte vocabularul în timp. Combină tehnici științifice de memorie cu moduri flexibile de învățare.

## 🚀 Funcții principale

### 🧠 Mai multe moduri de învățare
- **Învățare**: memorarea inițială a cuvintelor
- **Recapitulare**: întărește memoria prin repetare spațiată
- **Test**: quizuri pentru evaluarea progresului
- **Parcurgere rapidă**: învățare ușoară în pauze scurte

### ⏳ Planificare inteligentă a recapitulărilor
- Folosește **curba uitării Ebbinghaus**
- Ajustează frecvența după nivelul de stăpânire
- Reduce repetarea inutilă și crește eficiența

### 📊 Analize detaliate
- Urmărire vizuală pentru cuvinte învățate, neînvățate și în recapitulare
- Statistici zilnice și tendințe de învățare
- Urmărirea seriilor și a stăpânirii cuvintelor

### 📚 Gestionare flexibilă a vocabularului
- Liste pentru examene, uz zilnic și domenii profesionale
- Import de liste personalizate
- Categorii și etichete pentru organizare

### 🎯 Obiective
- Obiective zilnice personalizabile
- Mementouri pentru sarcini neterminate
- Motivație bazată pe serii
---

## 🎉 Concluzie
WordKing este mai mult decât o aplicație de vocabular; este o soluție completă pentru învățarea eficientă a cuvintelor. Planificarea inteligentă și datele fac vocabularul mai ușor, eficient și sustenabil.
