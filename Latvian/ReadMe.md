# 📘 WordKing vārdu krājuma lietotnes pārskats

## 🌟 Ievads
WordKing ir vārdu krājuma apguves rīks, kas paredzēts efektīvai vārdu iegaumēšanai. Tas ir piemērots angļu valodas apguvējiem, eksāmenu sagatavošanai un ikvienam, kurš vēlas ilgtermiņā paplašināt vārdu krājumu. Zinātniskas atmiņas metodes un elastīgi režīmi palīdz mācīties strukturēti un efektīvi.

## 🚀 Galvenās funkcijas

### 🧠 Vairāki mācīšanās režīmi
- **Mācīšanās**: sākotnēja vārdu iegaumēšana
- **Atkārtošana**: atmiņas nostiprināšana ar intervālu atkārtojumiem
- **Tests**: viktorīnas progresa novērtēšanai
- **Ātra pārlūkošana**: viegla mācīšanās īsās pauzēs

### ⏳ Gudra atkārtojumu plānošana
- Izmanto **Ebbinghaus aizmiršanas līkni**
- Pielāgo biežumu apguves līmenim
- Samazina lieku atkārtošanu un palielina efektivitāti

### 📊 Detalizēta analītika
- Vizuāla apgūto, neapgūto un atkārtojamo vārdu sekošana
- Dienas statistika un mācību tendences
- Sēriju un vārdu apguves uzskaite

### 📚 Elastīga vārdnīcas pārvaldība
- Saraksti eksāmeniem, ikdienai un profesionālām vajadzībām
- Savu vārdu sarakstu imports
- Kategorijas un birkas organizēšanai

### 🎯 Mērķi
- Pielāgojami dienas mērķi
- Atgādinājumi par nepabeigtiem uzdevumiem
- Motivācija ar mācību sērijām
