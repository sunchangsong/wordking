# 📘 WordKing 語彙学習アプリ概要

## 🌟 はじめに
WordKing は、単語を効率よく覚えるために設計された語彙学習ツールです。英語学習者、試験対策、長期的に語彙を増やしたい人に適しています。科学的な記憶テクニックと柔軟な学習モードにより、単語を体系的かつ効果的に習得できます。

## 🚀 主な機能

### 🧠 複数の学習モード
- **学習モード**：単語の初回記憶に集中
- **復習モード**：間隔反復で記憶を強化
- **テストモード**：クイズ形式で進捗を確認
- **クイック閲覧**：短い休憩時間の軽い学習に最適

### ⏳ スマート復習スケジュール
- **エビングハウスの忘却曲線**に基づいて復習を自動設定
- 習熟度に応じて復習頻度を調整
- 不要な反復を減らし効率を向上

### 📊 詳細な学習分析
- 学習済み、未学習、復習中の単語を可視化
- 日別統計と学習トレンド
- 継続日数と単語習熟度の追跡

### 📚 柔軟な語彙管理
- 試験、日常、専門分野など複数の単語リストに対応
- カスタム単語リストのインポート
- カテゴリとタグで整理

### 🎯 目標設定
- 毎日の学習目標をカスタマイズ
- 未完了タスクのリマインダー
- 継続に基づくモチベーション

---

## 🎉 まとめ
WordKing は単なる語彙アプリではなく、効果的な単語学習のための総合的なソリューションです。スマートなスケジュールとデータ分析により、語彙づくりをより効率的で簡単、継続しやすいものにします。
