# WordKing — 효율적인 우즈베크어 단어 암기를 위한 스마트 학습 도구

**WordKing**은 우즈베크어 학습자를 위해 만든 스마트 단어 암기 앱입니다. 과학적인 기억 알고리즘, 다양한 학습 모드, 데이터 기반 복습 메커니즘을 통해 사용자가 더 짧은 시간 안에 더 많은 단어를 확실히 익히도록 도와줍니다.

시험 준비(IELTS / TOEFL / 대학원 입시), 말하기 실력 향상, 일상 우즈베크어 어휘 축적까지 WordKing은 체계적이고 효율적인 학습 경험을 제공합니다.

---

## 🚀 핵심 기능

### 📚 다양한 학습 모드
- 단어 암기 모드: 단어 뜻을 빠르게 살펴보고 이해
- 철자 테스트 모드: 철자 능력 강화
- 듣기 훈련 모드: 듣고 구별하는 능력 향상
- 객관식 모드: 이해와 구분 능력 강화

> 다차원 훈련으로 단어 기억을 더 탄탄하게 만듭니다

---

### 🧠 스마트 복습 알고리즘
- 망각 곡선에 따라 복습 시간을 자동으로 배정
- 이미 익힌 / 자주 틀리는 / 아직 익히지 못한 단어를 자동 식별
- 학습 경로를 동적으로 최적화

> 가장 복습이 필요한 곳에 시간을 쓰세요

---

### 📊 학습 데이터 분석
- 일일 학습 통계
- 정답률 추세
- 기억 진행 상황 시각화
- 연속 학습 일수 기록

> 데이터로 성장을 이끌고 학습 동기를 높입니다

---

### 🎯 개인 맞춤 학습 계획
- 일일 학습 목표 설정(30 / 50 / 100단어)
- 다양한 단어장 지원(시험 / 일상 / 사용자 지정)
- 자투리 학습 시간에 맞춤

> 사용자마다 다른 학습 리듬을 충족합니다

---

## 📖 사용 가이드

### 1️⃣ 단어장 선택
앱을 열고 자신에게 맞는 단어장을 선택하세요(예: CET-4/6, IELTS, TOEFL, 사용자 지정 단어장)

### 2️⃣ 목표 설정
자신의 시간 계획에 맞춰 하루 학습량을 설정하세요. 예:
- 입문: 30단어 / 일
- 향상: 50단어 / 일
- 강화: 100단어 / 일

### 3️⃣ 학습 시작
다양한 모드로 단어를 학습하고 해당 테스트를 완료하세요

### 4️⃣ 계획에 따라 복습
시스템이 자동으로 복습을 알려 주고, 쉽게 잊는 단어를 중점적으로 강화합니다

### 5️⃣ 데이터 확인
학습 통계에서 학습 성과와 진전 추세를 확인하세요

---

## 🌟 제품 장점

### ✅ 과학적 기억
망각 곡선 기반의 스마트 복습 메커니즘으로 기억 효율을 높입니다

### ✅ 효율적인 학습
불필요한 반복을 줄이고 핵심 내용에 집중합니다

### ✅ 지속적인 동기 부여
데이터 피드백과 출석 체크 메커니즘으로 학습 동기를 강화합니다

### ✅ 유연하고 편리함
언제 어디서나 학습하며 자투리 시간을 충분히 활용합니다

---

## 🎯 적합한 사용자

- 📖 시험 준비생(CET-4/6 / 대학원 입시 / IELTS / TOEFL)
- 💼 직장인(우즈베크어 능력 향상)
- 🌍 우즈베크어 학습 애호가
- ⏱ 자투리 시간이 많은 사용자

---

## 🔍 왜 WordKing을 선택해야 할까요?

> WordKing의 핵심은 "많이 외우는 것"이 아니라 "기억에 남기는 것"입니다.

스마트 알고리즘과 데이터 분석을 통해 매번의 학습을 더 가치 있게 만듭니다.
