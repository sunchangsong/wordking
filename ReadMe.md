# 📘 WordKing Vocabulary Learning App Overview

## 🌟 Introduction
WordKing is a vocabulary learning tool designed for efficient word memorization. It is suitable for English learners, exam preparation, and anyone who needs to build vocabulary over time. By combining scientific memory techniques with flexible learning modes, WordKing helps users master words in a more structured and effective way.

## 🚀 Core Features

### 🧠 Multiple Learning Modes
- **Learning Mode**: Focus on initial word memorization  
- **Review Mode**: Reinforce memory based on spaced repetition  
- **Test Mode**: Simulate quizzes to evaluate progress  
- **Quick Browse**: Ideal for lightweight learning during short breaks  

---

### ⏳ Smart Review Scheduling
- Automatically schedules reviews based on the **Ebbinghaus Forgetting Curve**  
- Dynamically adjusts review frequency according to mastery level  
- Reduces unnecessary repetition and improves efficiency  

---

### 📊 Detailed Learning Analytics
- Visualized progress tracking (learned / unlearned / reviewing)  
- Daily statistics and learning trend analysis  
- Streak tracking to build consistent habits  
- Word mastery tracking  

---

### 📚 Flexible Vocabulary Management
- Supports multiple vocabulary lists (exams, daily use, professional, etc.)  
- Custom word list import  
- Categorization and tagging for better organization  

---

### 🎯 Goal Setting
- Customizable daily learning goals  
- Reminders for incomplete tasks  
- Streak-based motivation system  

---
