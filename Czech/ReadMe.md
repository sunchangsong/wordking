# 📘 Přehled aplikace WordKing pro učení slovní zásoby

## 🌟 Úvod
WordKing je nástroj pro učení slovní zásoby navržený pro efektivní zapamatování slov. Hodí se pro studenty angličtiny, přípravu na zkoušky i každého, kdo si dlouhodobě rozšiřuje slovní zásobu. Spojuje vědecké paměťové techniky s flexibilními režimy učení.

## 🚀 Hlavní funkce

### 🧠 Více režimů učení
- **Učení**: první zapamatování slov
- **Opakování**: posílení paměti intervalovým opakováním
- **Test**: kvízy pro kontrolu pokroku
- **Rychlé procházení**: lehké učení v krátkých pauzách

### ⏳ Chytré plánování opakování
- Využívá **Ebbinghausovu křivku zapomínání**
- Přizpůsobuje četnost úrovni zvládnutí
- Omezuje zbytečné opakování a zvyšuje efektivitu

### 📊 Podrobné analýzy
- Vizuální sledování naučených, nenaučených a opakovaných slov
- Denní statistiky a trendy učení
- Sledování série a zvládnutí slov

### 📚 Flexibilní správa slovní zásoby
- Seznamy pro zkoušky, běžné i profesní použití
- Import vlastních seznamů
- Kategorie a štítky pro lepší organizaci

### 🎯 Cíle
- Přizpůsobitelné denní cíle
- Připomenutí nedokončených úkolů
- Motivace založená na sériích
---

## 🎉 Závěr
WordKing je víc než aplikace na slovíčka; je to komplexní řešení pro efektivní učení slov. Chytré plánování a datové přehledy dělají budování slovní zásoby snazší, účinnější a udržitelné.
