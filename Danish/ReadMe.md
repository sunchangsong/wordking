# 📘 Oversigt over WordKing-appen til ordforråd

## 🌟 Introduktion
WordKing er et værktøj til ordforrådslæring, designet til effektiv memorering af ord. Det passer til engelskelever, eksamensforberedelse og alle, der vil opbygge ordforråd over tid. Videnskabelige hukommelsesteknikker og fleksible læringstilstande gør læringen struktureret og effektiv.

## 🚀 Kernefunktioner

### 🧠 Flere læringstilstande
- **Læring**: første memorering af ord
- **Gentagelse**: styrker hukommelsen med spaced repetition
- **Test**: quizzer til at vurdere fremskridt
- **Hurtig gennemgang**: let læring i korte pauser

### ⏳ Smart repetitionsplan
- Bruger **Ebbinghaus' glemselskurve**
- Justerer frekvens efter beherskelsesniveau
- Reducerer unødige gentagelser og øger effektivitet

### 📊 Detaljerede analyser
- Visuel status for lærte, ulærte og gentagelsesord
- Daglige statistikker og læringstendenser
- Sporing af streak og ordbeherskelse

### 📚 Fleksibel ordforrådsstyring
- Lister til eksamen, hverdag og professionelt brug
- Import af egne ordlister
- Kategorier og tags for bedre orden

### 🎯 Mål
- Tilpassede daglige mål
- Påmindelser om uafsluttede opgaver
- Motivation baseret på streaks
---

## 🎉 Konklusion
WordKing er mere end en ordforrådsapp; det er en samlet løsning til effektiv ordlæring. Smart planlægning og dataindsigt gør ordforrådsopbygning lettere, mere effektiv og bæredygtig.
