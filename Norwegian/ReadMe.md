# 📘 Oversikt over WordKing-appen for ordforråd

## 🌟 Introduksjon
WordKing er et verktøy for ordforrådslæring laget for effektiv memorering av ord. Det passer for engelskelever, eksamensforberedelse og alle som vil bygge ordforråd over tid. Vitenskapelige minneteknikker og fleksible læringsmoduser gjør læringen strukturert og effektiv.

## 🚀 Kjernefunksjoner

### 🧠 Flere læringsmoduser
- **Læring**: første memorering av ord
- **Repetisjon**: styrker minnet med spaced repetition
- **Test**: quiz for å vurdere fremgang
- **Rask gjennomgang**: lett læring i korte pauser

### ⏳ Smart repetisjonsplan
- Bruker **Ebbinghaus' glemselskurve**
- Justerer frekvens etter mestringsnivå
- Reduserer unødvendig repetisjon og øker effektivitet

### 📊 Detaljert læringsanalyse
- Visuell sporing av lærte, ulærte og repeterte ord
- Daglig statistikk og læringstrender
- Sporing av streak og ordmestring

### 📚 Fleksibel ordforrådsstyring
- Lister for eksamen, daglig bruk og profesjonelle behov
- Import av egne ordlister
- Kategorier og tagger for bedre organisering

### 🎯 Mål
- Tilpassede daglige mål
- Påminnelser om uferdige oppgaver
- Motivasjon basert på streaks
---

## 🎉 Konklusjon
WordKing er mer enn en vokabularapp; det er en helhetlig løsning for effektiv ordlæring. Smart planlegging og datainnsikt gjør ordforrådsbygging enklere, mer effektiv og bærekraftig.
