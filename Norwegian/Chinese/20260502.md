# WordKing — 高效学习挪威语词汇的智能学习神器

**WordKing** 是一款专为挪威语学习者打造的智能背单词 App，通过科学记忆算法、多种学习模式和数据驱动复习机制，帮助用户在更短时间内牢固掌握更多单词。

无论你是备考（雅思 / 托福 / 考研）、提升口语，还是日常挪威语词汇积累，WordKing 都能提供系统、高效的学习体验。

## 🚀 核心功能

### 📚 多种学习模式
- 单词记忆模式：快速浏览与理解词义 
- 拼写测试模式：强化拼写能力 
- 听力训练模式：提升听辨能力 
- 选择题模式：巩固理解与辨析 

> 多维度训练，让单词记忆更牢固

- 基于遗忘曲线自动安排复习时间

- 动态优化学习路径 

> 把时间用在最需要复习的地方

### 📊 学习数据分析
- 每日学习统计

## 📖 使用指南

### 1️⃣ 选择词库
打开 App，选择适合你的词书（如：四六级 / 雅思 / 托福 / 自定义词库）

### 2️⃣ 设置目标
根据自己的时间安排每日学习量，例如：
- 入门：30词 / 天 
- 提升：50词 / 天 
- 强化：100词 / 天 

### 3️⃣ 开始学习
通过多种模式学习单词，并完成对应测试

### 4️⃣ 按计划复习
系统自动提醒复习，重点强化易遗忘单词

### 5️⃣ 查看数据
在学习统计中查看你的学习成果和进步趋势
