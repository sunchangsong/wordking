# 📘 Обзор приложения WordKing для изучения слов

## 🌟 Введение
WordKing — это инструмент для изучения словарного запаса, созданный для эффективного запоминания слов. Он подходит изучающим английский, готовящимся к экзаменам и всем, кто постепенно расширяет словарный запас. Научные методы памяти и гибкие режимы помогают учить слова структурированно и результативно.

## 🚀 Основные функции

### 🧠 Несколько режимов обучения
- **Режим изучения**: первичное запоминание слов
- **Режим повторения**: закрепление памяти интервальными повторениями
- **Режим теста**: пробные викторины для оценки прогресса
- **Быстрый просмотр**: легкое обучение во время коротких пауз

### ⏳ Умное расписание повторений
- Планирует повторения по **кривой забывания Эббингауза**
- Меняет частоту в зависимости от уровня усвоения
- Сокращает лишние повторения и повышает эффективность

### 📊 Подробная аналитика
- Визуальный прогресс изученных, неизученных и повторяемых слов
- Ежедневная статистика и тренды обучения
- Отслеживание серии занятий и владения словами

### 📚 Гибкое управление словарями
- Поддержка списков для экзаменов, повседневного и профессионального использования
- Импорт пользовательских списков
- Категории и теги для лучшей организации

### 🎯 Постановка целей
- Настраиваемые дневные цели
- Напоминания о незавершенных задачах
- Мотивация через серии занятий
