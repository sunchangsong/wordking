# 📘 WordKing 词汇学习应用概览

## 🌟 简介
WordKing 是一款为高效记忆单词而设计的词汇学习工具。它适合英语学习者、考试备考者，以及任何需要长期积累词汇的人。通过结合科学记忆方法和灵活的学习模式，WordKing 帮助用户更有结构、更有效地掌握单词。

## 🚀 核心功能

### 🧠 多种学习模式
- **学习模式**：专注于初次记忆单词
- **复习模式**：基于间隔重复巩固记忆
- **测试模式**：通过模拟测验评估进度
- **快速浏览**：适合碎片时间轻量学习

### ⏳ 智能复习计划
- 根据**艾宾浩斯遗忘曲线**自动安排复习
- 按掌握程度动态调整复习频率
- 减少无效重复，提高学习效率

### 📊 详细学习分析
- 可视化跟踪已学、未学和复习中的单词
- 每日统计与学习趋势分析
- 连续学习记录与掌握度跟踪

### 📚 灵活词库管理
- 支持考试、日常、专业等多种词库
- 支持导入自定义词表
- 通过分类和标签更好地管理内容

### 🎯 目标设置
- 可自定义每日学习目标
- 未完成任务提醒
- 通过连续学习机制保持动力

---

## 🎉 总结
WordKing 不只是一款背单词应用，它是一套有效学习词汇的完整方案。借助智能复习计划和数据洞察，词汇积累会变得更高效、更轻松，也更可持续。
