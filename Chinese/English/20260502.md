# WordKing — A Smart Learning Tool for Efficient Chinese Vocabulary Memorization

**WordKing** is an intelligent vocabulary memorization app designed for Chinese learners. With scientific memory algorithms, multiple learning modes, and data-driven review mechanisms, it helps users master more words firmly in less time.

Whether you are preparing for exams (IELTS / TOEFL / postgraduate entrance exams), improving spoken Chinese, or building daily Chinese vocabulary, WordKing provides a systematic and efficient learning experience.

---

## 🚀 Core Features

### 📚 Multiple Learning Modes
- Word memorization mode: quickly browse and understand word meanings
- Spelling test mode: strengthen spelling skills
- Listening training mode: improve listening recognition
- Multiple-choice mode: reinforce understanding and distinction

> Multi-dimensional training makes vocabulary memory stronger

---

### 🧠 Smart Review Algorithm
- Automatically schedules review time based on the forgetting curve
- Automatically identifies mastered / error-prone / unmastered words
- Dynamically optimizes the learning path

> Spend time where review is needed most

---

### 📊 Learning Data Analysis
- Daily learning statistics
- Accuracy trends
- Memory progress visualization
- Consecutive study days tracking

> Drive progress with data and boost learning motivation

---

### 🎯 Personalized Learning Plan
- Customize daily learning goals (30 / 50 / 100 words)
- Supports multiple word banks (exam / daily / custom)
- Fits fragmented study time

> Meets different users' learning rhythms

---

## 📖 User Guide

### 1️⃣ Choose a Word Bank
Open the app and choose a word book that suits you, such as CET-4/6, IELTS, TOEFL, or a custom word bank.

### 2️⃣ Set a Goal
Set your daily learning volume according to your schedule, for example:
- Beginner: 30 words / day
- Improvement: 50 words / day
- Intensive: 100 words / day

### 3️⃣ Start Learning
Learn words through multiple modes and complete the corresponding tests.

### 4️⃣ Review on Schedule
The system automatically reminds you to review and focuses on strengthening easily forgotten words.

### 5️⃣ View Data
Check your learning results and progress trends in learning statistics.
