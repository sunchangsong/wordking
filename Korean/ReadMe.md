# 📘 WordKing 어휘 학습 앱 개요

## 🌟 소개
WordKing은 단어를 효율적으로 암기하도록 설계된 어휘 학습 도구입니다. 영어 학습자, 시험 준비자, 장기적으로 어휘를 늘리고 싶은 모든 사람에게 적합합니다. 과학적인 기억 기법과 유연한 학습 모드로 체계적이고 효과적인 단어 학습을 돕습니다.

## 🚀 핵심 기능

### 🧠 다양한 학습 모드
- **학습 모드**: 단어를 처음 외우는 데 집중
- **복습 모드**: 간격 반복으로 기억 강화
- **테스트 모드**: 퀴즈처럼 진행 상황 확인
- **빠른 보기**: 짧은 휴식 시간의 가벼운 학습에 적합

### ⏳ 스마트 복습 일정
- **에빙하우스 망각 곡선**에 따라 복습을 자동 예약
- 숙련도에 맞춰 복습 빈도 조정
- 불필요한 반복을 줄이고 효율 향상

### 📊 상세 학습 분석
- 학습 완료, 미학습, 복습 중 단어의 시각적 추적
- 일일 통계와 학습 추세
- 연속 학습과 단어 숙련도 추적

### 📚 유연한 어휘 관리
- 시험, 일상, 전문 분야 등 여러 단어장 지원
- 사용자 단어 목록 가져오기
- 카테고리와 태그로 정리

### 🎯 목표 설정
- 맞춤형 일일 학습 목표
- 미완료 과제 알림
- 연속 학습 기반 동기 부여

---

## 🎉 결론
WordKing은 단순한 어휘 앱이 아니라 효과적인 단어 학습을 위한 종합 솔루션입니다. 스마트 일정과 데이터 인사이트로 어휘 확장을 더 효율적이고 쉽고 지속 가능하게 만듭니다.
